# Test1757 channel-layout experiment

The Windows x64 job verifies the prefetch BMI2 executable from GitHub Actions run 42543250921. It locates the unique 512-byte prefix of the original nn-18cd32e11a9c.nnue inside that executable and extracts the 138,360,528-byte network at the recorded offset. Both the executable and the extracted network must match their pinned SHA-256 digests. A sparse checkout supplies the two retired 128-game PGNs at lab commit 6831500a4c6b22d64109a38bb0dc5bbf5b6f8fe0. The verifier reads their Git blobs and checks their byte counts and SHA-256 digests. The input receipt records the embedded offset, the executable digest and each PGN blob ID. [Accepted build](https://github.com/0mis/Stockfish/actions/runs/42543250921) · [Published game evidence](https://github.com/0mis/stockfish-weight-space-lab/tree/6831500a4c6b22d64109a38bb0dc5bbf5b6f8fe0/results).

The workflow pins CPython 3.11.9 x64, the NumPy 2.4.6 Windows wheel, and the chess 1.11.2 source distribution. It installs pinned setuptools and wheel on the runner to build chess. [NumPy release files](https://pypi.org/pypi/numpy/2.4.6/json) · [Chess release files](https://pypi.org/pypi/chess/1.11.2/json).

After the tests pass, the workflow runs the experiment with the four files in the inputs directory. A successful analysis writes its final receipt to evidence/RESULT.json. A negative held-out result completes normally and preserves the text evidence. A true heldout_gate_passed and a matching candidate_sha256 authorize the upload of the final candidate produced after native equality and inverse checks. Its verified copy appears at verified-layout-candidate/candidate.nnue in the one-day artifact. This experiment uses retired game data and measures implementation behavior.
