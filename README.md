This fixed experiment compares the exact released history/prefetch executable plus d5 with the official Nov9 Windows universal executable plus original 18cd. It measures the complete bundles; a differential cannot be attributed solely to weights.

All 286 distinct legal-EP FEN4 starting families from the five named public test1757 PGNs are included once: **286 reversed pairs / 572 games**, at **10+0.1 / T1 / H64**. Two disjoint standard windows-2022 hosts each play 143 fixed pairs, with at most two concurrent hosts and one game per host. The hash order, first colors, clock/failure policy and exact whole-sample descriptive paired uncertainty were frozen before outcomes in PLAN.json and openings.json.

The frozen public schedule was independently admitted before native play. ROOT-ADMISSION.json contains only aggregate clearance and public-data commitments; it contains no private ID or individual membership verdict. The implementation pins that exact receipt, the immutable schedule and both released engine/net combinations. Each host must freshly verify both configured benchmark signatures and perft4 before games. No partial scores are printed or inspected, and no outcome retries or adjudication are allowed.

This is a known retired development population, **not fresh confirmation**. It does not use the new natural-play screen or private pools, and is separate from the ongoing matches and the net-only Fishtest test. No alpha, farm submission, main/release edit or strength announcement is made. Raw PGNs, clock comments, native configurations, process identities and every failure are retained in the two run artifacts.
