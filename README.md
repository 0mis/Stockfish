# Public test1758 fixed readout-bias development match

This isolated driver branch compares the exact released history-floor executable on **both** sides: Shawn Xu's unedited test1758 parent network versus a fixed transfer of the lab's nine previously published output-bias deltas. This is not new training on test1758, an official-Stockfish comparison, private trial4 evidence, or a strength announcement.

The immutable plan is `public-dev/plan.json`. It declares **128 reversed-opening pairs / 256 games**, **10+0.1 / T1 / H64**, sequential public prior-PGN pair order, alternating first-listed side across pairs, fresh engines per game, concurrency1, no strength limit/tablebases/evaluation adjudication and no score-based stopping/retry. Only the already-public, retired 256-game development PGNs supply openings. No private formal source or opening is used.

Every completed legal referee two-game outcome is retained, including reported clock forfeits after played moves. Raw PGN clock comments, referee/UCI trace, NDJSON clock events and process/command hashes are preserved. Incomplete/zero-move/native/referee/parse failures stop the experiment as incomplete, with no pair retry. A startup repair is allowed only when no game result/PGN exists, preserving the same model hashes, plan, order, clocks and sample size.

The job runs only on the standard public GitHub-hosted **windows-2022** label, with no larger/self-hosted runner, billing change or custom secret. Workflow permission is contents:read; checkout credentials are not retained; native child environments exclude Actions/GitHub credentials. This exact branch is the only push trigger. Evidence-only commits do not match its path filter. No Fishtest, X or release operation is performed.

The fixed recipe authenticates the entire donor, all192routes/92storedheads, published offset/delta map, all stored tags and exact EOF; it produces the exact f92 candidate and verifies inverse/11changedbytes. Both actual runtime binaries and networks are SHA-pinned. No local native build or engine run is required to stage this branch.

After the full sample, paired points and all128rawpair receipts are independently rechecked. The scoped nominal95% interval is exact integer empirical paired-bootstrap percentile uncertainty over128iidempiricalpair draws, with no interpolation or new seed. It remains descriptive for these retired development openings and this standard hosted VM; no formal or global gain is claimed.
